# Keyboard

## Field

| Key | Action |
|---|---|
| <kbd>Arrow Down</kbd> | open and move focus into the popover |
| <kbd>Enter</kbd> | read the typed text; closes an open popover |
| <kbd>Escape</kbd> | close; when closed, undo typed text |
| <kbd>Enter</kbd>, <kbd>Space</kbd> | open (range pill and read-only range field) |

## Calendar

| Key | Action |
|---|---|
| <kbd>Arrow Left</kbd> / <kbd>Arrow Right</kbd> | previous / next day (mirrored in right to left) |
| <kbd>Arrow Up</kbd> / <kbd>Arrow Down</kbd> | same day previous / next week |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | previous / next month |
| <kbd>Shift</kbd> + <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | previous / next year |
| <kbd>Home</kbd> / <kbd>End</kbd> | first / last day of the week |
| <kbd>Enter</kbd>, <kbd>Space</kbd> | pick the day (range: start, then end) |
| <kbd>Escape</kbd> | close and return focus to the field |
| <kbd>Tab</kbd> | next control in the popover, out of the popover closes it |

## Time row

| Key | Action |
|---|---|
| <kbd>Arrow Up</kbd> / <kbd>Arrow Down</kbd> | step the focused part |
| <kbd>0</kbd> to <kbd>9</kbd> | type the part, focus moves on after two digits |
| <kbd>A</kbd> / <kbd>P</kbd> | AM / PM |
| <kbd>Tab</kbd> | next part |
| <kbd>Enter</kbd>, <kbd>Escape</kbd> | close |

The mouse wheel over a part steps it too.

## Presets

| Key | Action |
|---|---|
| <kbd>Arrow Up</kbd> / <kbd>Arrow Down</kbd> | previous / next preset |
| <kbd>Home</kbd> / <kbd>End</kbd> | first / last preset |
| <kbd>Enter</kbd>, <kbd>Space</kbd> | pick |
